# Python Programming Practicals

## Overview
This repository contains three beginner-friendly Python programs developed using Google Colab with AI assistance. The practical demonstrates basic programming concepts and the use of Python dictionaries.

## Programs Included

### 1. Factorial (`factorial.py`)
Calculates the factorial of a number entered by the user. Negative numbers are handled with an appropriate message.

### 2. Fibonacci Series (`fibonacci.py`)
Generates the Fibonacci series for the number of terms specified by the user.

### 3. C Structure to Python Dictionary (`structure_to_dictionary.py`)
Demonstrates how student information represented by fields in a C structure can be represented using a Python dictionary.

## Technologies Used
- Python 3
- Google Colab
- GitHub
- AI-assisted code generation and documentation

## How to Run
1. Open the required Python file.
2. Copy its code into a Python environment, such as Google Colab.
3. Run the program.
4. Enter the requested input, if applicable, and observe the output.

## Key Learning Outcomes
- Using variables, conditional statements, and loops.
- Calculating factorials and generating Fibonacci sequences.
- Representing structured information using Python dictionaries.
- Understanding key differences between C and Python.
- Using GitHub to store and document source code.
- Using AI assistance to improve code documentation.
